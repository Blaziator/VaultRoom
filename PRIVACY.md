# Privacy note

VaultRoom is an independent community project built for the NamoID
"safer-document-room" engineering challenge. It is a proof-of-concept demo,
not a production service.

- Do not upload real identity documents, financial records, or any other
  genuine personal data. Use obviously fictional test files only.
- Authentication is handled entirely by NamoID Hosted Auth; this application
  never sees your NamoID password or credentials.
- Uploaded files are stored in a demo database for the purpose of this
  challenge and may be deleted at any time without notice.
- This project is not affiliated with, endorsed by, or audited by NamoID.

Questions about this project can be directed to the repository owner via
GitHub: https://github.com/Blaziator/VaultRoom
